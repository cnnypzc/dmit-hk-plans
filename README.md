## 超量之后会发生什么，这事对月付特别重要

月付最大的价值是容错。而容错的关键在于：流量跑超的那一天，你会被停机，还是被限速。

T1 系列给的是“限速不限量”方案：流量用完后端口降到 50Mbps / 100Mbps / 200Mbps / 500Mbps / 1Gbps（按档位递增），服务不停，也不额外扣钱。这意味着月初没算准流量的情况下，你至少不会在月中突然面对一台死机，而是有一段降速缓冲期去决定要不要升档。

Pro 系列的超出策略不同，EB 系列则被渠道记录为超量后暂停。这两条线上的预测误差成本更高，也就更需要月付来兜底——先跑一个月摸清实际流量曲线，比一上来压一年更稳。
